# Contributing

Thanks for taking the time to contribute.

1. Fork the repository and create a focused branch.
2. Install dependencies with `composer install` and `npm install`.
3. Run `php artisan test` and `npm run build` before opening a pull request.
4. Keep pull requests small, explain the change, and include tests for changed behavior.

Never commit `.env`, API keys, database dumps, receipt images, or other personal financial data.
